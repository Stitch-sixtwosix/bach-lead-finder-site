# BACH Lead Finder

Public website for the BACH Development lead finder: Planned Development (PD/PUD), rezoning and
site-plan cases from local-government agendas nationwide, ranked as construction leads.

Open it at **https://stitch-sixtwosix.github.io/bach-lead-finder-site/**

This repository only holds the built website. It is updated automatically from the private
project repository. Map data © OpenStreetMap contributors, Esri, US Census.
